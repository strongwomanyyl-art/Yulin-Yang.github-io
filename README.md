\## 研究概况

硕士阶段围绕水产动物品质评价及其分子机制开展研究，重点研究不同产地与养殖模式下鲍鱼的营养、风味及热加工品质差异，并结合蛋白质组学与代谢组学解析品质形成机制。具备水产动物样品处理、品质指标检测、多组学数据分析及分子生物学实验基础，同时具有海参实验饲料制备和室内养殖系统搭建的实践经验，希望博士阶段进一步开展甲壳动物/水产动物营养品质形成与调控研究。
